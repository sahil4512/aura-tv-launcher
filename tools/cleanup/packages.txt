# Packages tools/tv-cleanup may turn off. Only packages actually on the TV are shown.
# Everything is turned off with `pm disable-user` and can be turned back on with
# `tools/tv-cleanup <tv-ip>:5555 --restore`. Nothing is ever uninstalled.
#
# Format:  tier  package  what it is · what you lose (if anything)
#
# Tiers:
#   safe      background services, ads, telemetry and unused extras. You lose nothing you'd notice.
#   optional  a feature some people use. Turned off only when you say yes to each one.
#   home      the TV's own home screen and its recommendation services. Turned off only with
#             --replace-home, and only when Aura is installed. If Aura doesn't become Home
#             afterwards, they're turned straight back on.
#
# Contributions welcome: add a line per package, with what it does and what turning it off costs.
# Please only add packages you've turned off on a real TV without problems.
